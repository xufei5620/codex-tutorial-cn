安装、登录与界面

  • 预计阅读 12 分钟

本章目标

在自己的电脑上装好应用、登录、切换到 Codex，并且认识界面上的几个主要区域。读完后你还会明白「权限模式」是什么——这是安全使用 Codex 最重要的一个设置。

3.1开始前：你需要什么

需要说明
一台电脑macOS：macOS 14 或更新，Apple 芯片（M1 及之后）或 Intel 芯片都可以，官方下载页默认给出的是 Apple 芯片版本。Windows：通过 Microsoft Store 安装，官方没有写明最低版本；一般需要 Windows 10 或 11，并且 Microsoft Store 能正常使用。
一个 ChatGPT 账号没有就在登录时顺手注册，需要一个邮箱。所有套餐（包括免费）都能使用 Codex，只是每 5 小时和每周的用量额度不同，用完要等额度恢复或购买额外额度。
网络安装和使用都要联网。Codex 是在线服务，你的对话会发送到服务器处理（第 1 章的隐私底线由此而来）。
大约 20 分钟下载、安装、登录、认识界面。别赶时间，看到不认识的提示框就停下来读一读。
关于地区可用性：OpenAI 在官方帮助中心公布了 ChatGPT 的支持国家和地区名单，中国大陆与香港目前不在名单内；欧洲部分地区有些功能（如操作电脑、记忆）暂不开放。名单会变化，请以官方页面为准（链接见第 11 章 11.2）。本教程只讲在支持地区的正常使用方法，不提供任何绕开地区限制的做法——那样做可能违反服务条款，也可能违反你所在地的法规。

3.2先弄清楚：现在的 Codex 在哪里

这一点很容易让人绕晕，先说清楚。2026 年 2 月，OpenAI 发布了独立的「Codex 桌面应用」；到了 2026 年 7 月 9 日，这个应用并入了新的「ChatGPT 桌面应用」。现在你要安装的软件叫 ChatGPT，装好以后，应用左上角的菜单里有三个视图：Chat（普通聊天）、Work（工作）、Codex。本教程说的「Codex」，就是这第三个视图。

三件容易弄错的事：

  • 别下载成「ChatGPT Classic」。下载页上还有一个叫 Classic（经典版）的旧应用，它没有 Codex。要装的是不带 Classic 字样的 ChatGPT。
  • 网页版和手机 App 里用不了 Codex。Codex 视图只在 macOS 和 Windows 的桌面应用里有。手机 App 只能远程查看电脑上正在进行的 Codex 对话。
  • 网上很多资料讲的是「Codex CLI」。那是给程序员用的命令行版本，和本教程无关（第 1 章说过，我们不讲命令行）。看到满屏黑底白字的命令，说明那份资料不是给你看的。

3.3Windows 安装步骤

  1. 打开官方下载页。在浏览器地址栏输入 chatgpt.com/download 并回车。你应该看到 OpenAI 的下载页面，上面有 Windows 和 macOS 的下载按钮。只从这个官方地址下载，不要从搜索结果里的其他网站下载安装包。
  2. 点 Windows 的下载按钮。它会打开 Microsoft Store（Windows 自带的应用商店），显示名为「ChatGPT」的应用页面。确认应用名不带「Classic」。
  3. 在 Store 里点「获取」或「安装」。你应该看到进度条，等它走完。如果 Store 让你登录 Microsoft 账号，登不登都可以试试，通常不登录也能安装。
  4. 打开应用。安装完成后点「打开」，或者在开始菜单搜索「ChatGPT」。你应该看到应用窗口，上面有登录按钮。

预期结果：桌面或开始菜单里出现 ChatGPT 应用，能正常打开到登录界面。接下来跳到 3.5。

Windows 版的 Codex 底层默认使用 PowerShell（Windows 自带的一个命令执行工具）来完成它的工作。你不需要碰它。极少数情况下应用会提示需要调整 PowerShell 的「执行策略」——遇到这种提示不要自己改设置，按 3.8 的方式求助。

3.4macOS 安装步骤

  1. 打开官方下载页。在浏览器地址栏输入 chatgpt.com/download 并回车。页面会自动识别你的 Mac 芯片类型，给出对应的下载按钮。确认按钮不带「Classic」字样。
  2. 下载 .dmg 文件。点下载后，浏览器右上角会显示下载进度；完成后在「下载」文件夹里能看到一个 .dmg 文件（这是 Mac 上常见的安装包格式）。
  3. 双击 .dmg，把图标拖进「应用程序」。通常会弹出一个小窗口，左边是 ChatGPT 图标，右边是「Applications（应用程序）」文件夹——把左边拖到右边即可。这一步官方文档没有细写，属于 macOS 安装应用的通用做法。
  4. 从「启动台」或「应用程序」文件夹打开 ChatGPT。首次打开时 macOS 可能弹出「是否打开从互联网下载的应用」的确认框，点「打开」。你应该看到应用窗口和登录按钮。

预期结果：「应用程序」文件夹里有 ChatGPT，能正常打开到登录界面。

官方说明 Intel 芯片的 Mac 也能安装（下载页会给出对应版本），但 Codex 视图里某些功能是否在 Intel 机器上完整可用，官方没有明确说明。如果你的 Mac 是 2020 年以前的 Intel 机型，遇到功能缺失时先不要怀疑自己操作错了。

3.5首次登录，切换到 Codex

  1. 点「Continue to sign in」（继续登录）。应用会打开你的浏览器，跳到 OpenAI 的登录页。没有账号就在这里注册，用邮箱即可。
  2. 在浏览器里完成登录。输入邮箱和密码（或用其他账号登录）。成功后浏览器会提示「可以回到应用了」，有时会问「是否允许打开 ChatGPT」，点允许。
  3. 回到应用，找到左上角的菜单。你应该看到自己已登录，界面默认可能停在 Chat 或 Work 视图。点应用左上角的菜单，选择 Codex。
  4. 看到 Codex 视图。左侧是一列侧栏，中间偏下是一个大输入框。到这里就算成功了。

预期结果：左上角显示当前是 Codex 视图，输入框可以点进去打字。

登录时只在浏览器里输入密码，只输入在 OpenAI 的官方登录页（地址以 openai.com 或 chatgpt.com 结尾）。任何在对话框里、弹窗里、或者别的网站上要你输入 ChatGPT 密码、验证码的地方，都不要输。登录界面还有一个「Sign in another way」（用其他方式登录）选项，那是给开发者输入 API 密钥用的，你不需要它。

3.6界面导览：认识五个区域

Codex 视图的界面大致分五块。先认个脸熟，不用现在就把每个按钮都点一遍。

区域在哪里它是干什么的
侧栏窗口左侧列出你的东西：Chats（对话）、Projects（项目，也就是你让它处理的文件夹）、Scheduled（定时任务）、Activity（需要你关注的对话汇总）。顶部有搜索框。
输入框窗口中下方你打字、粘贴材料、发送请求的地方。可以拖文件进去作为材料。
输入框下面的两个小选择器紧贴输入框下沿一个是模型选择（用哪个 AI 模型，新手用默认即可），另一个是权限模式（Codex 被允许做到什么程度——3.7 专门讲）。
对话与审阅区窗口中间大块显示 Codex 的回复。当它修改了你文件夹里的文件时，这里会出现一个审阅面板（review panel），逐行显示改了什么，并提供撤销（撤销能力的边界见第 5 章 5.4）。
设置（Settings）头像菜单里（具体位置以实际界面为准）分为 General（通用）、Notifications（通知）、Appearance（外观）、Personalization（个性化，含「记忆」开关）、Computer Use（操作电脑）、Browser（内置浏览器）等。新手只需要知道它在哪。

还有两个东西你会在后面章节遇到：Plugins（插件，第 6 章）和输入 $ 弹出的 Skill 菜单（第 7 章）。现在不用管。

「新建对话」时会问你两件事

点新建对话，Codex 可能让你选在哪里工作：Local（本机的某个文件夹）、Worktree（给程序员用的隔离副本）、Cloud（云端）。零基础读者记两条就够：只是聊天、不需要它碰文件，就什么都不选直接开始；需要它整理某个文件夹里的文件，就选 Local 并挑一个专门为练习新建的文件夹。第 8 章会详细讲。

3.7权限模式：先弄懂再动手

这是本章最重要的一节。Codex 和普通聊天机器人最大的不同是：它可以替你动手——改文件、上网查资料、运行电脑上的程序。「权限模式」决定它做这些事之前要不要先问你。输入框下面那个选择器里通常有这几项：

模式它能做什么适合谁
Ask for approval
（先问我）		默认模式。可以读写你指定的那个文件夹里的文件、运行常规操作；要上网、或要碰文件夹以外的东西时，先弹窗问你。本教程全程使用这个模式。
Approve for me
（替我审批）		边界和上面一样，但越界请求改由一个 AI 审阅员自动审核，并显示风险等级。熟练之后、处理低风险任务时可以考虑。新手不用。
Full access
（完全访问）		去掉沙盒和审批：可以改电脑上任何文件、随时上网、不再问你。不要用。看到它就当它不存在。

当 Codex 弹出审批请求时，通常可以选「允许一次」「本次对话都允许」「永久允许」。新手一律选允许一次，看清楚它要做什么再点。看不懂它要做什么，就点拒绝——拒绝永远不会造成损失。

三条规矩，从今天起就遵守：
  • 权限模式永远留在 Ask for approval。如果发现被改成了别的，改回来。
  • 让它处理文件时，只给它一个专门新建的练习文件夹，不要把「桌面」「文档」整个交给它。
  • 审批弹窗出现时，先读完再点。文字里出现「删除」「delete」「remove」「发送」「支付」这类词，一律先拒绝，回头想清楚。

第一次打开某些文件夹时的系统提示

macOS 在 Codex 第一次访问「桌面」「下载」「文稿」等文件夹时，会弹出系统级的授权提示；Windows 也可能有类似的确认。这是操作系统在替你把关，属于正常现象。只对你准备用来练习的文件夹点允许；对「音乐」「照片」之类它没理由碰的文件夹，点不允许。

3.8装不上、登不进怎么办

现象先试这些
下载页打不开或很慢换一个网络试试；确认地址是 chatgpt.com/download，没有拼错。
Windows 的 Microsoft Store 打不开或安装失败先在 Store 里随便安装一个别的免费应用，确认 Store 本身正常；重启电脑再试一次。
macOS 提示「无法打开，因为它来自身份不明的开发者」先确认你是从官方地址下载的。如果是，在「系统设置 → 隐私与安全性」底部通常有「仍要打开」。如果不是官方地址下载的，删掉重下。
登录时浏览器显示地区不支持（英文提示里含 unsupported_country 之类字样）这表示你当前所在地区不在官方支持名单内。请看 3.1 的「停一停」——本教程不提供绕开方法。
登录成功，但左上角菜单里找不到 Codex确认装的不是 Classic 版本；把应用更新到最新版（应用内通常有更新提示）；退出重新登录一次。
提示用量已达上限不是故障。免费与付费套餐的额度不同，等提示里给出的时间过后再用，或到账号的用量页面查看。

都试过还不行，按第 10 章 10.5 的五要素把问题写清楚，去官方帮助中心（help.openai.com）求助。求助前把截图里的邮箱等个人信息打码。

本章小结

  • 现在的 Codex 是「ChatGPT 桌面应用」左上角菜单里的一个视图；别装成 Classic，网页和手机上用不了。
  • 只从 chatgpt.com/download 下载；登录只在浏览器里的官方页面输入密码。
  • 界面五块：侧栏、输入框、模型/权限选择器、对话与审阅区、设置。
  • 权限模式永远留在 Ask for approval；只给它专门的练习文件夹；审批弹窗读完再点，看不懂就拒绝。
  • 地区不支持时不要绕，装不上就按 3.8 排查、按 10.5 求助。
