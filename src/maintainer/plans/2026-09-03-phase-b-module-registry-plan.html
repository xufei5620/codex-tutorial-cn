正式课程 V1 阶段 B：模块目录实施计划

对应任务：GitHub Issue #3。

基线：PR #2 合并候选 bbe321d9c25602396c540280c31eef4daa0cfbcf；本阶段使用独立分支 codex/phase-b-module-registry，不继续修改阶段 A。

1. 目标与边界

把当前 65 个编号课程小节和 6 张提示词卡登记为 71 个可独立审校的内容单元。只建立身份、状态和证据字段，不把任何草稿提升为已审校或已验证。

  • 11 个“本章小结”补稳定锚点，但作为章节派生内容，不计入模块目录。
  • 不新增尚不存在的 20 张行业提示词卡，不建立数据库、API 或 Notion 双向同步。
  • 不在本阶段改写课程观点、安装步骤或案例正文；发现的问题进入后续章节审校任务。

2. 已确认的数据决策

  • 课程模块使用永久 ID CDX-M-0001 至 CDX-M-0065，按当前阅读顺序一次性分配；以后标题、排序或章节变化不得重编号。
  • 提示词卡保留 PRM-COM-0001 至 PRM-COM-0006。
  • 旧章级 CDX-M-0101 等 11 个 ID 只登记为 legacyChapterPlaceholders，不得复用为小节身份。
  • 正文保留现有 #s1 等公开锚点，并在对应 section 增加 data-unit-id；小结使用 #summary。
  • 当前 71 个单元全部保持 contentStatus=draft、verificationState=unverified、verificationDate=null、lastReviewedDate=null、rights=pending。
  • 多数模块平台为 Windows 与 macOS；ch03#s3 仅 Windows，ch03#s4 仅 macOS。
  • 26 张唯一提示词卡 / 30 个展示位的正确口径为：6 张通用卡，加四个行业各 5 张专属卡并各复用 1 张共享卡。

3. 文件设计

  • src/modules-v1.json：唯一可编辑的 71 单元目录源。
  • src/maintainer/schemas/modules-v1.schema.json：目录 Schema。
  • registry/modules-v1.json 与 schemas/modules-v1.schema.json：构建生成并进入在线 manifest 与离线 ZIP。
  • tests/test_module_registry.py：数量、身份、状态、路径、HTML 映射、隐私与生成闭环测试。

单元最小字段为：id、kind、title、chapterId、collectionKeys、taskKey、order、sourceAnchor、publicPath、platforms、risk、contentStatus、verificationState、verificationDate、sourceRefs、rights、lastReviewedDate。公开目录不保存指向离线包外部的 authoring 路径。

4. 实施任务

  1. 先写失败测试。固定 65 + 6 = 71、ID 集合、旧 ID 不复用、双状态不混用、日期格式、相对公开路径和隐私路径拒绝规则。
  2. 建立 Schema 与目录源。使用 additionalProperties=false；为 lesson-module 与 prompt-card 写条件约束；录入 65 个小节和 6 张现有卡，不创建未来占位卡。
  3. 标记 HTML。给 65 个编号 section 与 6 张卡增加 data-unit-id，给 11 个小结补 id="summary"；保留旧公开深链。
  4. 接入构建。确定性复制目录与 Schema，加入首页/README 维护入口、根 manifest、SHA256SUMS 和离线 ZIP。
  5. 接入严格检查。用 Draft 2020-12 与 FormatChecker 校验；要求公开 HTML 与目录 ID、标题、路径、章节、集合精确一致；拒绝盘符、UNC、..、URL scheme、.codex 和内部工作树路径。
  6. 统一维护说明。修正旧生命周期文字，说明 Notion 只是目录投影；修正提示词库 26/30 的数学口径；章级旧 ID 只保留迁移说明。
  7. 生成与复验。Windows 与 Ubuntu 分别运行完整测试、严格检查、构建与字节比较；对新增 registry 做独立冷审。

5. 验收门槛

  • 71 个单元在源目录、公开目录和 HTML 中一一对应；无重复 ID、路径或容器顺序。
  • 删除记录、增加未登记 section、标题漂移、非法状态/日期/路径、复用旧 ID均会使严格检查失败。
  • 所有初始状态仍为 draft + unverified；没有把撰写日期冒充正式复核日期。
  • 公开 registry 与 Schema 同时存在于在线 manifest 和离线 ZIP，且不含本机路径或内部备注。
  • Windows/Linux 构建一致，现有读者深链不失效，阶段 A 的全部 42 项测试继续通过。
