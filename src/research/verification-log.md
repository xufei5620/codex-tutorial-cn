# 验证记录（0.2.2 实测轮）

填写说明（读完再填；规则详见 `src/HANDOFF.md` §2.1、§5）：

- 每个测试项一行；没做的也要有一行，判定写 `unverified`（未做）或 `unsupported`（无法在此环境做）并写原因。
- 「判定」只用六个词：`verified` / `verified-with-limitations` / `verification-failed` / `unverified` / `unsupported` / `verification-expired`。
- 「观察」写原话：界面英文照抄，中文提示照抄；不要写「和教程一样」这种没信息量的话——至少写出你看到的名称或文案。
- 「正文改动」写章节小节 + 一句话；没改写「无」。`verification-failed` 的行必须有改动或在报告里说明为什么不改。
- 证据文件放 `src/research/evidence/<windows|macos>/`，文件名以测试项 ID 开头；此表「证据」列写文件名即可。
- 不写任何真实账号、邮箱、姓名、真实路径中的用户名。
