# 常见问题

## 充值后没到账

支付成功后一般 1 分钟内自动到账，偶尔会因支付通道回调延迟几分钟。超过 10 分钟仍未到账，请把 **订单号** 和 **注册邮箱** 发给[客服](/contact)。

## 费用是怎么计算的

按每次调用实际消耗的 token 数 × 模型单价 × 分组倍率扣费，价格以[定价页](https://xm.solov.cc/pricing)为准。每次调用的扣费明细在[日志](https://xm.solov.cc/usage-logs)里能查到，包括输入、输出、缓存各消耗了多少。

## 令牌和余额是什么关系

余额在账户上，令牌只是使用余额的"钥匙"。给令牌设了额度上限时，用完上限会先报"令牌额度已用尽"，即使账户还有余额；调高上限或新建一把令牌即可。

## 一个账号能创建几把令牌

不限。建议按用途分开创建（比如一把给 Codex、一把给脚本），各自设额度上限，泄露时只需停用那一把。

## 本地 Codex / Claude Code / Gemini CLI 调不通

按顺序检查：

1. 接口地址是否写对：Codex / Claude Code / Gemini CLI 填 `https://xm.solov.cc`，Cline / OpenCode / Hermes 填 `https://xm.solov.cc/v1`；
2. 令牌是否复制完整、是否已启用、是否过期；
3. 令牌的**分组**是否包含你填的模型；
4. 配置文件是否保存成功、格式是否正确（JSON 多一个逗号都会失败）；
5. 客户端是否已经**完全重启**。

仍然报错，对照[错误码对照](/errors)，或把完整报错文案发给[客服](/contact)。

## 模型名填什么

以[定价页](https://xm.solov.cc/pricing)为准，教程里的模型名只是示例。填了分组里没有的模型会返回"无可用渠道"或"模型不存在"。

## 支持哪些接口格式

三种都支持，接口地址统一是 `https://xm.solov.cc`：

- OpenAI 兼容：`/v1/chat/completions`、`/v1/embeddings`、`/v1/images/generations`
- Anthropic 兼容：`/v1/messages`
- Google Gemini 兼容：`/v1beta/models/{model}:generateContent`

## 可以开发票吗

可以。登录后在顶栏「聊天」菜单里进入开票中心，按提示提交已完成的充值订单。

## 令牌泄露了怎么办

立即在[令牌页面](https://xm.solov.cc/keys)停用旧令牌，再重新创建一把。日志里可以核对这期间有没有异常调用。

## 怎么联系客服

见[联系客服](/contact)：企业微信在线客服，每日 9:00–23:00（北京时间）。联系时请附上注册邮箱，以及订单号（充值问题）或完整报错文案（调用问题）。
