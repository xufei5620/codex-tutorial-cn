# 注册、充值与令牌

官网：<https://xm.solov.cc>。账户余额、令牌限制和模型价格请以本站控制台为准。已连接成功的用户可以进入 [Codex 零基础](/learn/codex/)学习实际使用。

<SupportCard />

## 1. 注册并登录

打开 [注册页面](https://xm.solov.cc/register)，按当前页面完成验证。官网密码、令牌和模型厂商账号不是同一种凭据。

## 2. 充值并核对状态

进入 [钱包](https://xm.solov.cc/wallet)查看方式、金额和规则。订单状态不明确时不要重复支付，保留订单号、时间和状态，在确认的客服会话中核查。

有兑换码时使用 [兑换入口](https://xm.solov.cc/redemption-codes)，不要公开未使用的兑换码。

## 3. 创建令牌

进入 [令牌页面](https://xm.solov.cc/keys)，为设备或用途设置名称。分组、额度、期限和模型限制按当前页面支持情况填写，先看 [模型、分组与定价](/guide/models)。

令牌的额度上限不是额外赠送的账户余额。不要公开令牌、认证头、Cookie 或密码。怀疑泄露时先停用旧令牌，再创建新令牌并更新使用位置。

## 4. 按具体工具配置

不同客户端拼接请求路径的方式不同，不能用“所有工具都不带 /v1”的规则。先看 [地址与协议](/guide/connection-basics)，再进入对应接入教程。

[Codex](/clients/codex) · [Claude Code](/clients/claude-code) · [Gemini CLI](/clients/gemini-cli) · [其他工具](/guide/choose-tool)。

使用 [管理工具](/guide/manager)前，确认实际发行版支持本站。

## 5. 核对调用和费用

完成 [最小调用验证](/guide/verify)，到 [用量记录](https://xm.solov.cc/usage-logs)核对时间、模型、状态和费用。文本成功不代表图片、工具调用等全部功能均已验证。
