# 错误码对照

按客户端报错里引号内的文案查最准。本页会根据 xm.solov.cc 的真实日志持续补充。

::: warning 这几种错误重试没有用
`令牌额度已用尽`、`令牌已过期`、`用户余额不足`、`无可用渠道`、`无权使用模型`。它们都需要你改配置或到控制台处理，脚本自动重试只会一直失败。
:::

## 令牌与余额

| 报错文案 | 状态码 | 原因 | 怎么办 |
|---|---|---|---|
| `无效的令牌` / `invalid token` | 401 | 令牌错误：复制不完整、多了空格、用了别的站的令牌，或已删除 | 到 [令牌页](https://xm.solov.cc/console/token) 重新复制完整令牌 |
| `令牌已过期` | 401 | 令牌设置了有效期且已过 | 新建一把令牌，或编辑令牌延长有效期 |
| `令牌额度已用尽` | 429 / 403 | 这把令牌**自己设置的额度**用完了（不是账户余额） | 编辑令牌调高额度，或新建一把 |
| `用户余额不足` / `insufficient balance` | 403 | 账户余额不足 | [充值](https://xm.solov.cc/console/topup)后重试 |
| `该令牌状态不可用` / `令牌已被禁用` | 401 | 令牌被停用 | 到令牌页启用，或新建一把 |

## 分组与模型

| 报错文案 | 状态码 | 原因 | 怎么办 |
|---|---|---|---|
| `分组 xxx 下模型 xxx 无可用渠道` / `无可用渠道` | 503 | 这个分组暂时没有能提供该模型的渠道，或模型名写错 | 到[定价页](https://xm.solov.cc/pricing)核对准确的模型名；确认令牌分组包含该模型；持续出现请联系客服 |
| `该令牌无权使用模型 xxx` | 403 | 令牌限制了可用模型 | 编辑令牌的模型限制，或换一把令牌 |
| `当前分组负载已饱和，请稍后再试` | 429 | 该分组渠道繁忙 | 稍后重试，或换一个分组的令牌 |

## 频率与上游

| 报错文案 | 状态码 | 原因 | 怎么办 |
|---|---|---|---|
| `Too Many Requests` / `rate limit` | 429 | 触发频率限制或上游限流 | 降低并发，稍后重试 |
| `上游错误` / `Bad Gateway` / `upstream error` | 502 / 503 | 上游模型服务暂时故障 | 等 1–5 分钟再试；持续半小时以上看公告或联系客服 |
| `模型不存在` / `The model does not exist` | 404 | 模型名写错或该模型已下线 | 核对定价页的准确名称 |

## 客户端里还可能看到的

| 报错文案 | 状态码 | 原因 | 怎么办 |
|---|---|---|---|
| `504 Gateway Time-out` | 504 | 长请求或上下文压缩超时 | 重试；另起新对话；Codex 可调小上下文 |
| `413 Request Entity Too Large` | 413 | 请求体超过接收上限 | 另起一个新对话 |
| `Your request was blocked` / 带 `cf-ray:` | 403 / 503 | 被 Cloudflare 拦截，常见于代理或 IPv6 出口 | 关闭代理用国内环境直连；关闭 IPv6 |

## 还是解决不了

把**完整报错文案**、使用的模型和大致时间发给[客服](/contact)（每日 9:00–23:00），我们会在日志里定位这次请求。
