# System button marks

These assets identify the operating system choices. They do not imply endorsement.

- `windows.svg`: exact WindowsLogoIcon path and original viewBox from [Microsoft Fluent UI](https://github.com/microsoft/fluentui/blob/master/packages/react-icons-mdl2-branded/src/components/WindowsLogoIcon.tsx). Copyright Microsoft Corporation, MIT license; see `WINDOWS-LICENSE.txt`.
- `apple.svg`: exact regular Apple navigation logo path from [Apple's website](https://www.apple.com/), fetched 2026-10-03. Only the surrounding navigation whitespace was cropped in the viewBox; the path geometry is unchanged. Apple and its mark belong to Apple Inc.
- `linux.png`: unchanged Tux image referenced by [kernel.org's own stylesheet](https://www.kernel.org/theme/css/main.css) at `../images/logos/tux.png`. Tux was created by Larry Ewing using GIMP. [kernel.org's FAQ](https://www.kernel.org/faq.html) describes its use and credit requirement.

SVGs contain paths only, with no script, external references, or embedded markup. Buttons keep visible system names; icons are decorative and are bundled locally.
