# 常见问题

## 网站里没有数据

刚注册或刚创建密钥时，用量页面没有数据是正常的。只要开始调用，统计就会逐步出现。

## 刷新后还是没变化

统计同步需要一点时间，等几秒再刷新一次。

## 兑换成功但余额没看到变化

先回到控制台刷新页面。如果账号已经过期，需要先续期，再查看余额和使用情况。

## 充值后没到账

支付成功后一般 1 分钟内自动到账，偶尔会因支付通道回调延迟几分钟。超过 10 分钟仍未到账，请把 **订单号** 和 **注册邮箱** 发给[客服](/contact)。

## 本地 Codex / Claude Code / Gemini CLI 调不通

按顺序检查：

1. 接口地址是否写对：Codex / Claude Code / Gemini CLI 填 `https://api.solov.cc`，OpenClaw 填 `https://api.solov.cc/v1`；
2. 密钥是否复制完整、是否已启用；
3. 密钥的**分组**是否包含你填的模型（分组决定能用哪些模型）；
4. 配置文件是否保存成功、格式是否正确（JSON 多一个逗号都会失败）；
5. 客户端是否已经**完全重启**。

仍然报错，对照[错误码对照](/errors)，或把完整报错文案发给[客服](/contact)。

## 模型名填什么

以 [可用渠道](https://api.solov.cc/available-channels) 页面为准，教程里的模型名只是示例。填了分组里没有的模型会返回 503 或"模型不支持"。

## 一个账号能创建几把密钥

不限。每把密钥绑定一个分组，互不影响，建议按用途分开创建，泄露时只需停用那一把。

## 密钥泄露了怎么办

立即在「API 密钥」页面停用旧密钥，再重新创建一把。请不要把密钥发给别人或提交到公开仓库。

## 怎么联系客服

见[联系客服](/contact)：企业微信在线客服，每日 9:00–23:00（北京时间）。联系时请附上注册邮箱，以及订单号（充值问题）或完整报错文案（调用问题）。
