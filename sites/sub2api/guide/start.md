# 注册、订阅与密钥

官网：<https://api.solov.cc>。第一次使用依次完成账户、订阅或可用额度、密钥和工具配置；已连接成功可以直接阅读 [Codex 零基础](/learn/codex/)。

<SupportCard />

## 1. 注册并登录

打开 [注册页面](https://api.solov.cc/register)，按当前页面要求完成邮箱验证并登录。允许的邮箱类型以页面提示为准；需要帮助时联系本站客服。

![注册页面参考](/img/image-32.png)

截图用于辨认功能，控件名称和字段以当前页面为准。本站账号不是模型厂商的官方账号，不要混用密码和凭据。

## 2. 准备订阅或额度

根据实际方案在控制台的订阅、充值或兑换入口操作。付款前确认额度、期限、适用模型与规则。支付后检查订单及额度状态，不明确时先保留订单号、时间和状态，不重复支付。

![兑换页面参考](/img/image-11.png)

![订阅页面参考](/img/image-26.png)

只在确认的客服会话中提供必要订单信息，不公开验证码或未使用兑换码。

## 3. 创建 API 密钥

进入 [API 密钥页面](https://api.solov.cc/keys)。名称标明设备或用途，分组按实际套餐与可用模型选择。

![API 密钥页面参考](/img/image-7.png)

![创建密钥参考](/img/image-5.png)

密钥不要发送到群聊或提交公开仓库。怀疑泄露时先停用，再创建新密钥并更新各工具配置。

## 4. 选择一个工具并验证

[选择工具](/guide/choose-tool) → [地址与协议](/guide/connection-basics) → 对应接入教程 → [验证第一次调用](/guide/verify)。

使用 [星芒管理工具](/guide/manager)前，先确认当前发行版与本站服务对应。
