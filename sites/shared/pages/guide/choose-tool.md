# 选择适合你的教程

不需要把所有工具都装一遍。第一次使用，选一个符合任务的入口，完成接入和小任务验证后再扩展。

| 教程分类 | 从哪里开始 |
| --- | --- |
| **Claude** | [Claude 教程](/learn/claude/)：区分 [Claude Code 接入](/clients/claude-code)与 [Claude 桌面应用](/clients/claude-desktop)，再做 [第一次练习](/learn/claude/first-task) |
| **Codex** | [Codex 接入](/clients/codex)：按需选择 CLI、桌面应用或 IDE 扩展，接通后读 [Codex 零基础](/learn/codex/) |
| **星芒管理工具** | [管理工具教程](/guide/manager)：下载安装、检查环境并按当前版本支持范围配置目标工具 |

## 几个容易混淆的名称

Claude 桌面应用、Claude Code、Codex CLI 和 Codex 桌面入口是不同的使用方式。CLI 在终端运行，IDE 扩展在编辑器里运行；桌面应用提供图形界面。安装了其中一个，不代表其他入口也安装或配置好了。

星芒管理工具负责帮助安装和配置，不是 Claude 或 Codex 的对话界面。通过管理工具应用配置后，还需打开目标客户端做一次小任务。

官方账号登录和本站%%KEY_WORD%%也不是同一种认证。使用本站服务，必须确认工具允许设置对应协议的自定义服务地址；仅支持官方账号的功能，不能因为填写了本站密钥就认定可以使用。

## 选择后，按这个顺序走

[注册与准备](/guide/account) → [理解地址与协议](/guide/connection-basics) → 对应工具教程 → [验证调用](/guide/verify) → [第一次任务](/learn/first-task)。

第一次只完成一个入口：例如先让 Codex CLI 返回一条文本，再决定是否安装桌面应用或 IDE 扩展。编辑器安装成功、客户端能打开、配置能保存，都还没有证明本站调用成功。

工具能够设置地址、本站渠道是否兼容、管理工具是否能自动配置，是三个分别核对的问题。具体版本与实际开放模型，以本站说明及 [模型页面](%%MODELS_URL%%)为准。
