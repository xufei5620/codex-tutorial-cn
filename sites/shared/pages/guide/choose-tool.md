# 选择适合你的工具

不需要把所有工具都装一遍。第一次使用，选一个符合任务的入口，完成接入和小任务验证后再扩展。

| 你要做什么 | 建议先看 |
| --- | --- |
| 使用 Codex 理解材料、协助文件或项目任务 | [OpenAI / Codex 接入](/clients/codex)，接上后读 [零基础课程](/learn/codex/) |
| 使用 Claude 的编程工具 | [Claude Code](/clients/claude-code) |
| 在终端使用 Gemini | [Gemini CLI](/clients/gemini-cli) |
| 使用 xAI 的终端编程工具 | [Grok Build](/clients/grok-build) |
| 使用独立 Agent 工具 | [Hermes](/clients/hermes)、[OpenClaw](/clients/openclaw)、[OpenCode](/clients/opencode) |
| 了解 DeepSeek Harness 的本地界面 | [DeepSeek Harness](/clients/deepseek-harness) |
| 在编辑器内完成开发任务 | [Cursor](/clients/cursor)、[VS Code](/clients/vscode) |
| 不熟悉安装与配置 | [星芒管理工具](/guide/manager)，先核对当前版本支持的工具与本站入口 |

## 几个容易混淆的名称

AI 厂商、模型、桌面应用、CLI 与 IDE 扩展不是同一个概念。IDE 是开发环境类别，不是某家厂商必然拥有的一个独立产品。某个产品提供多种使用方式时，在同一篇文章内区分，不要求读者重复配置多个虚构入口。

官方账号登录和本站%%KEY_WORD%%也不是同一种认证。使用本站服务，必须确认工具允许设置对应协议的自定义服务地址；仅支持官方账号的功能，不能因为填写了本站密钥就认定可以使用。

## 选择后，按这个顺序走

[注册与准备](/guide/start) → [理解地址与协议](/guide/connection-basics) → 对应工具教程 → [验证调用](/guide/verify) → [第一次任务](/learn/first-task)。

工具能够设置地址、本站渠道是否兼容、管理工具是否能自动配置，是三个分别核对的问题。具体版本与实际开放模型，以本站说明及 [模型页面](%%MODELS_URL%%)为准。
