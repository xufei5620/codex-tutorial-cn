# 管理工具新版说明

这一页按管理工具 0.2.21 写，讲最近几版新加了什么、按钮挪到了哪里、哪些东西改了名字。自己装的是哪一版，在管理工具的「设置 › 版本更新」里能看到；还是旧版的，先看下面的 [自动更新](#auto-update)。

第一次用管理工具，先照 [管理工具使用教程](/guide/manager)一步步做完，再回来看这一页。

## 常用的东西挪到了哪里 {#where}

| 想做的事 | 现在去哪里 |
| --- | --- |
| 装 Claude Code、Codex 等工具 | 首页那个工具的卡片，点「安装」 |
| 更新、重新安装、卸载工具 | 卡片右下角的「…」 |
| 网络加速、备份、版本更新 | 「设置」里的「网络加速」「备份迁移」「版本更新」 |
| 充值、看用量、管密钥 | 点左下角的账号进「个人中心」；侧栏也有「充值」 |
| 留言反馈、看运行日志 | 侧栏「反馈与客服」 |
| 找不到某个按钮或设置 | 按 Ctrl K（Mac 上按 ⌘ K），输入想找的字，比如「自动下载更新」「线路」 |

## 改了名字的叫法 {#names}

| 以前叫 | 现在叫 |
| --- | --- |
| Key、API Key | 密钥（就是本站控制台里的%%KEY_WORD%%） |
| 游戏加速 | 网络加速 |
| 默认线路、CF | 线路1 |
| 直连、洛杉矶 | 线路2 |
| 软件更新 | 版本更新 |
| 反馈 | 反馈与客服 |
| 使用星芒账号 | 当前账号（就是管理工具左下角登录的那个账号） |

## 连接线路：线路1 和线路2 {#routes}

管理工具连本站有两条线路，叫「线路1」「线路2」。两条用的是同一个账号、同一份余额，换线路不会换账号，也不用重新登录。

- 在「设置 › 网络加速 › 连接线路」里能选「自动（推荐）」「只用线路1」「只用线路2」，保存后重启管理工具才生效。
- 选「自动」时，管理工具会自己挑能连上的那条：星芒账号先走线路2，历史账号先走线路1，连不上就自动换另一条，不用你操作。
- 首页每张工具卡片中间那行，写着这个工具现在走哪条线路。换了线路以后，已经开着的 Claude Code、Codex 要关掉重开才走新线路；Claude Desktop、WorkBuddy、OpenCode 完全退出后，管理工具会自动替它们换过去。
- 两条都连不上时，首页会说清是什么原因，并给一个「重新检测」按钮。

没有特别原因，保持「自动（推荐）」就好。

## 自动更新 {#auto-update}

管理工具的新版本会在后台下好，等你退出管理工具或下次打开时自动装上，不打断正在用的工具。

- 点窗口的关闭只是缩到托盘，不算退出。
- Windows 装的时候会弹一次授权窗口，点「是」就好，装完自动打开。
- Mac 换新版本后第一次打开，可能弹出钥匙串密码框：输入这台 Mac 的开机密码，点「始终允许」。点了「拒绝」看着像被退出了登录，下次打开还会再问。
- 不想自动装：在「设置 › 版本更新」里关掉「自动下载更新」，以后有新版本会先提醒你，由你点安装。
- 想马上装：在「设置 › 版本更新」点「下载更新」，下好后先保存手头的工作，再点「重启并安装」。

管理工具自己的版本，和 Claude Code、Codex 这些工具的版本是两回事。工具出了新版本，首页那张卡片上会写「可更新到 v…」，点它就行。

## 官方账号和当前账号一键切换 {#switch-account}

首页每张工具卡片左下角有个小标签，写着这个工具现在用谁的账号：

- 「当前账号」：用的是管理工具左下角登录的这个账号的余额。
- 「官方账号」：用的是你自己的 Claude 或 ChatGPT 订阅，按官方的规则计费，不扣本站余额。
- 「自己的密钥」：用的是你自己填进去的那把密钥。

点这个小标签，或者点卡片右下角「…」里的「改用当前账号」「切回官方账号」，就能切换。管理工具会先备份原来的设置；Claude Code、Codex 切完还会自动测一次能不能连上，连不上就恢复原样。切完把已经开着的工具关掉重开。Claude Desktop 也能这样切，切完要完全退出再打开。

## Codex 桌面端和 ChatGPT 账号 {#codex-chatgpt}

Codex 桌面端（Mac 上叫 ChatGPT）窗口左侧栏最上面能切换模式。用本站账号时，请切到「Codex」再发消息。

- 在「聊天」「工作」里发消息会报「提交消息时出错」，下面还带一句 Work browser access requires an authenticated account。这两项要登录 ChatGPT 账号才能用，跟密钥、余额没关系，换到「Codex」里发就好。
- 想用自己的 ChatGPT 账号：在首页 Codex 桌面端卡片的「…」→「配置…」里选「ChatGPT 账号」并保存，再到 Codex 里登录。这样花的是你自己的 ChatGPT 订阅，不扣本站余额；登录、套餐这类问题请找 OpenAI 官方，本站客服帮不上。
- 中文界面要先登录管理工具，再从管理工具点「打开」才有。直接点 Codex 自己的图标打开是英文。
- Codex 桌面端和 Codex CLI 用的是同一份设置，改了一个，另一个也跟着变。

## Gemini CLI 不再由管理工具管理 {#gemini}

从 0.2.19 起，管理工具不再安装、更新 Gemini CLI，也不再替它准备密钥、换账号、换线路，首页也不再有它。

- 已经装了的不会被删，照常能用。
- Gemini 模型还在，账号能用哪些以 [模型页面](%%MODELS_URL%%)为准。
- 想自己给 Gemini CLI 接本站，按 [Gemini CLI 接入教程](/clients/gemini-cli)手动配置。

## 最近几版新加的功能 {#new-features}

**装工具、打开工具**

- 第一次点「打开」不再让你选文件夹：管理工具会在「文档」里建好一个练习文件夹，直接在里面打开（Mac 上建在个人文件夹里）。想换文件夹，点卡片「…」里的「选择其他文件夹…」。
- 卡片「…」里的「接着之前的对话…」：能看到这个工具在每个文件夹里最近的那次对话，点「接着聊」就能接上。
- 通过管理工具更新过的 Claude Code、Codex CLI，更新后用着不对劲，可以在卡片「…」里点「退回更新前的 v…」装回原来那一版，更新后 14 天内都能退。
- 卸载后提示有文件没删干净时，点「帮我清理」，管理工具核对后替你删掉。
- Windows 上的 WorkBuddy 改成到腾讯官网自己下载：卡片上点「去官网下载」，装好后回来点「重新检测」，之后照常一键配置、打开。
- Claude Desktop、WorkBuddy、OpenCode 的卡片「…」里有「卸载…」，点了会告诉你在系统里怎么删。

**外接工具、技能、插件**

- Codex、Grok CLI 的外接工具，和 Claude Code、Codex CLI、Grok CLI 的插件，都能用开关停用、再打开，不用删了重加、重填参数。
- Claude Code、Grok CLI 的技能也能「从文件夹导入」、移除了；移除的先放进管理工具的回收站。
- Grok CLI 也能装插件了。点「添加」后会先说清插件装好后会在电脑上自动运行哪些东西，点「信任并安装」才装。
- 只装了 Codex 桌面端、没装 Codex CLI，也能加外接工具和技能。
- 星芒生图技能改名叫 images：在 Codex 里输入 $images、在 Claude Code 里输入 /images 就能用，原来的设置会自动带过去。

**网络加速**

- 「游戏加速」改名叫「网络加速」，在「设置 › 网络加速」里。现在走的是本站自己的一条美国线路，专门用来打开 ChatGPT、Codex 这些 OpenAI 的服务；开着加速时，别的网站照常直接连。
- 从管理工具打开 Codex 桌面端、Claude Desktop 时，会在后台自动连上加速，不扣免费时长，用完自动断开。以前国内网络下 Claude Desktop 报「Host Claude Code binary not available」，就是缺了这一步。

遇到问题，带上管理工具的版本号、看到的提示和发生时间，联系 [本站客服](/contact)。
