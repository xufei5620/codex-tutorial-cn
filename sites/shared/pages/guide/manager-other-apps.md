# 把当前账号用在 OpenClaw、Hermes 里

OpenClaw、Hermes Agent 是装在自己电脑上、可以一直开着的 AI 助手。星芒 AI 管理工具不替你安装、也不管理它们，但它们可以花管理工具左下角那个账号（当前账号）的余额：把一个地址、一把密钥、一个模型名填进去就行。

这一页讲这三样在管理工具里去哪儿拿、怎么填。OpenClaw、Hermes 本身怎么装，看 [OpenClaw 接入与本地使用](/clients/openclaw) 和 [Hermes Agent 接入教程](/clients/hermes)。

<ManagerAccountNotice compact />

## 1. 给它单独建一把密钥 {#new-key}

每个助手单独建一把，名字写清楚。哪天不想让它用了，撤销这一把就行，Claude Code、Codex 这些工具照常用。

1. 点管理工具左下角的账号，进「个人中心」，切到「密钥管理」。
2. 点「新建密钥」，名称写「OpenClaw」或「Hermes」。分组决定这把密钥能用哪些模型，没有特别要求就用默认选好的那个。
3. 「额度」保持默认的「限额」，「可用额度」默认填的是 10（单位是美元），按你能接受的金额改。用完这把密钥就会暂停，不影响账号余额。这类助手开着就会自己干活，别选「不限额度」。
4. 点「创建密钥」。

**完成标志：** 密钥列表里多了一把你刚起名的密钥。

## 2. 复制地址 {#address}

1. 还在「密钥管理」，翻到最下面「用在别的软件里」。首页工具区最后一格「看看怎么用在别的软件里」也能直接跳到这里。
2. 点以 `/v1` 结尾的那一行右边的「复制」。OpenClaw 和 Hermes 都填这一行：

```text
%%OPENCLAW_BASE_URL%%
```

「用在别的软件里」是管理工具 0.2.24 起才有的。找不到这一块，就直接复制上面这行地址，或者到「设置 › 版本更新」把管理工具更新到最新版。

**完成标志：** 地址已经复制下来，结尾是 `/v1`。

## 3. 复制密钥 {#copy-key}

1. 在密钥列表里找到刚建的那把，点它右边的复制图标（鼠标停上去写着「复制密钥」）。
2. 1 分钟内粘贴到 OpenClaw 或 Hermes 里。为了安全，管理工具复制的密钥 1 分钟后会从剪贴板清掉，过了时间就再点一次复制。

密钥只粘贴在自己电脑上的设置里，不要发到聊天群、截图或客服对话中。管理工具里的「密钥」，就是网页控制台里的%%KEY_WORD%%，是同一样东西。

## 4. 记下模型名 {#model}

模型名要一字不差。打开 [本站模型页](%%MODELS_URL%%)，找你这把密钥的分组能用的模型，复制它的模型名（模型 ID）。

**完成标志：** 手上有三样：以 `/v1` 结尾的地址、刚建的那把密钥、一个模型名。

## 5. 填进 OpenClaw {#openclaw}

**还没装：** 照 [OpenClaw 接入与本地使用](/clients/openclaw) 装好。初始化向导问用哪个模型提供方时，选「自定义提供方」（英文界面叫 Custom provider），兼容方式选 OpenAI，再按提示依次粘贴地址、密钥，填上模型名。

**已经装好：** 照那一篇的 [第 3 节](/clients/openclaw#site-config) 改配置文件：`baseUrl` 填刚复制的地址，`apiKey` 填密钥，`REPLACE_WITH_MODEL_ID` 换成模型名。保存后重启网关，新设置才生效。

## 6. 填进 Hermes {#hermes}

1. 照 [Hermes Agent 接入教程](/clients/hermes) 装好。Hermes 现在 Windows 和 Mac 都能直接装，不用另外准备 Linux 环境。
2. 在终端运行下面这条，打开选模型的向导。

```text
hermes model
```

3. 在列表里选「Custom Endpoint」（自定义地址），按提示粘贴地址和密钥，再填上模型名，保存。

向导里的选项名字会随版本变，以你装的那一版为准。

## 7. 发一句话试试，再看扣费 {#verify}

1. 在 OpenClaw 或 Hermes 里发下面这段话。

```text
这是连接测试。请用一句话回复“连接测试完成”。
不要联网，不读写文件，不执行其他工具。
```

2. 收到回复后，回管理工具「个人中心 › 用量账单」，看有没有刚才那个时间、那个模型的一条记录。

**完成标志：** 助手回了话，用量账单里有对应的记录。到这里就接好了。

## 用之前要知道的几件事 {#notes}

- 扣的是当前账号的余额，跟 Claude Code、Codex 用的是同一份。能用哪些模型，跟你复制的那把密钥的分组走。
- 只要助手在调用模型就会扣钱，包括你设的定时任务、接进来的聊天软件里别人发的消息。不用的时候把它关掉，或者给这把密钥设好限额。
- 管理工具里换了账号，OpenClaw、Hermes 不会跟着换，还是用原来那把密钥、扣原来那个账号的钱。想换，就在新账号里再建一把，重新填一遍。
- 在密钥那一行的「…」里点「撤销密钥」，助手就用不了了。想再用，新建一把重新填。
- 管理工具首页不显示 OpenClaw、Hermes，「检查」页也不查它们，有问题看下面这张表。
- 这类助手能在你电脑上执行命令、接微信等聊天软件。先只做文字对话，每项权限看懂了再打开。

## 连不上怎么办 {#trouble}

| 看到什么 | 怎么办 |
| --- | --- |
| 认证失败、密钥无效、401 | 多半是密钥没粘全，或者过了 1 分钟没粘上。回「密钥管理」重新复制一次再粘；也看看那一行是不是写着停用、过期或额度用完 |
| 模型不存在、没有权限用这个模型 | 模型名差一个字都不行。回 [本站模型页](%%MODELS_URL%%) 核对这把密钥的分组能不能用它 |
| 地址不对、404 | 要用以 `/v1` 结尾的那一行，不要用「用在别的软件里」的第一行或第三行 |
| 余额不足 | 到管理工具「个人中心 › 充值订阅」充值 |
| 一直没反应 | 先在管理工具首页打开 Codex 或 Claude Code 发一句话。那边能回，说明账号没问题，再回 OpenClaw、Hermes 那一篇的排错表查 |

还是不行，按 [连接排错](/guide/troubleshooting) 记下时间、模型和报错原文，再联系 [客服](/contact)。截图前遮住密钥。
