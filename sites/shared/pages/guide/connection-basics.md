# 地址、协议与密钥

本站入口是 `%%SITE_URL%%`。在 [密钥页面](%%KEYS_URL%%)创建并管理%%KEY_WORD%%，在 [模型页面](%%MODELS_URL%%)确认当前可用模型。

## 1. 不要把不同网址混用

| 名称 | 用途 |
| --- | --- |
| 官网／控制台 | 用浏览器注册、查看费用和管理资料 |
| 教程网址 | 阅读操作方法，不是模型 API 地址 |
| Base URL | 客户端发请求时使用的基址，可能需要协议前缀 |
| 完整端点 | 一次请求的完整路径，通常不能整段填进 Base URL |

模型 ID 要精确对应当前分组允许的名称。展示名称、厂商模型名称、本站调用 ID 可能不同，不能仅凭拼写相似替换。

## 2. 按协议选地址

| 协议 | 典型端点形态 | 注意 |
| --- | --- | --- |
| OpenAI Chat Completions | `/v1/chat/completions` | 不等同于 Responses |
| OpenAI Responses | `/v1/responses` | Codex 等工具需要相应兼容能力 |
| Anthropic Messages | `/v1/messages` | 请求格式与认证要求不同 |
| Gemini | `/v1beta/models/{model}:generateContent` | 不能用普通 OpenAI 地址冒充原生协议 |

端点仅用于理解结构，不代表本站每个分组都开放全部接口。带不带 `/v1` 取决于具体工具如何拼接最终路径；请看对应教程，不要盲目重复添加或删除。

## 3. 分开保管不同凭据

官网密码用于登录账户；本站%%KEY_WORD%%用于调用本站 API；官方平台密钥用于官方服务；插件或网关令牌用于它们自己的功能。不能交叉替代，也不要在公开截图中展示。

优先为不同设备或用途创建可识别的密钥，并根据控制台支持情况设置额度、期限和模型限制。怀疑泄露时先停用，再更新各个使用位置。

## 4. 注意配置生效范围

用户配置、项目配置、当前终端环境变量与远程环境的配置可能互相覆盖。本机、WSL、容器和远程电脑也可能各自独立。只在一个终端中设置变量，不等于另一个已经打开的桌面应用能读取。

第一次配置先备份，只改必要字段；保留客户端默认的权限确认，不以绕过确认作为连通条件。
