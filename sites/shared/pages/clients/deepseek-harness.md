# DeepSeek Harness 入门说明

DeepSeek Harness 是插件化 Agent 工具。本页对应官方项目的本地 Web 使用方式，不把网页界面说成已经取得的 Windows 或 macOS 原生安装包。

## 1. 先读项目说明

项目处于开发者预览阶段时，配置和兼容性可能变化。开始前阅读 [官方 README](https://github.com/deepseek-ai/deepseek-harness)及其安全说明，并记录实际版本。

## 2. 启动本地界面

根据官方 README，在满足 Node.js 要求的环境中运行：

```text
npx @deepseek-ai/dsh web
```

查看终端打印的实际本地地址。官方默认通常为 `http://127.0.0.1:3080`，但端口和运行环境应以本次输出为准。首次安装确认包名与来源，不在含真实敏感资料的目录练习。

## 3. 先选模型插件，再配提供方

在当前版本支持的模型插件或提供方设置中，分别确认：自定义基址、认证字段、模型 ID、协议和工具调用能力。不要把其他客户端的 YAML、环境变量或整份配置直接复制给 Harness。

本站账号与模型信息从 [控制台](%%CONSOLE_URL%%)和 [模型页面](%%MODELS_URL%%)核对。插件只支持官方服务或协议不匹配时，先停止，不用未经确认的字段凑出一份“通用配置”。

## 4. 用小任务验证

先测试简单文本，再测试自己需要的一项工具能力。只允许练习目录，首次不安装陌生插件，不开放整台电脑，也不把本地界面暴露到公网。

客户端可启动、配置可保存、模型能回复和完整 Agent 工作流通过，是不同的检查结果，应分别记录。

## 5. 更新与恢复

更新前备份当前配置、插件清单和任务资料；开发者预览版本可能出现不兼容变化。出现问题时提供版本、插件、模型和脱敏错误，必要时恢复已确认的旧版本或配置。
