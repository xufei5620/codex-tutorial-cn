# Claude Desktop 安装与账号说明

Claude Desktop 是带窗口的 Claude 应用。先选对安装包、完成启动，再确认要使用的账号与功能。安装软件本身不会给账号增加订阅权益，也不会自动接入星芒。

第一次安装：先看 [下载准备](#prepare)，再只做 [Windows](#windows) 或 [Mac](#mac) 中的一种安装。已经能打开应用：直接去 [确认账号](#account)。已经登录：可从 [第一次对话](#first-chat)开始。

## 1. 先选你要使用的入口 {#choose-entry}

| 你想做什么 | 从哪里开始 | 账号与费用看哪里 |
| --- | --- | --- |
| 在桌面窗口中对话、整理一段文字 | 本篇安装 Desktop，进入聊天入口 | Claude 官方账号的套餐与用量 |
| 使用 Cowork 或桌面中的 Code 功能 | 检查应用当前提供的入口、套餐与组织权限 | 对应官方权益或组织部署配置 |
| 用星芒密钥在终端读取、修改项目文件 | [Claude Code 接入教程](/clients/claude-code) | 本站密钥所属分组、额度与调用记录 |
| 不想手动安装和填写 CLI 配置 | [星芒管理工具](/guide/manager) | 管理工具中的本站账号与工具配置 |

**Claude Code** 可以在终端运行，桌面应用里也可能有 Code 入口；安装 Desktop 不等于系统终端已有 `claude` 命令。需要终端操作时仍按 CLI 教程检查版本。

**完成标志：** 已确定要用 Desktop 官方聊天，还是星芒 CLI。选择 CLI 时转到对应教程；选择 Desktop 时继续下面的准备。

## 2. 下载前准备 {#prepare}

1. Windows 打开“设置 → 系统 → 系统信息/关于”，查看系统类型。常见 Intel/AMD 电脑选 x64；ARM 电脑选 ARM64，不根据外观猜测。
2. Mac 点左上角苹果菜单 →“关于本机”，查看芯片和系统版本。标为 Universal 的包同时适配 Intel 与 Apple 芯片；有单独架构选项时按实际芯片选。
3. 打开 [本站安装包下载区](/guide/manager#download-installers)，找到 **Claude Desktop**，核对系统、架构、版本和文件后缀。不要误下星芒管理工具或 Codex 安装包。
4. 对照 [Claude 官方安装要求](https://support.claude.com/en/articles/10065433-install-claude-desktop)检查系统。应用能安装与某个功能能运行是两件事，Code、Cowork 可能还有各自要求。

本站下载列表没有适合设备的条目，或浏览器显示下载未完成时，先停止安装，记录系统与文件名向 [客服](/contact)核对。不要把一个系统的包改后缀后安装。

**完成标志：** 已知道系统、架构和包格式。Windows 继续 [下一节](#windows)；Mac 跳到 [macOS 安装](#mac)，不用执行另一系统的步骤。

## 3. Windows 安装 {#windows}

1. 在 [本站安装包下载区](/guide/manager#download-installers)选择 Claude Desktop 的 Windows x64 或 ARM64 条目，等待下载完成。
2. 先展开下载条目的 **“安装说明与校验”**，核对该版本的校验信息和安装方式。MSIX 或离线包应按条目给出的实际步骤操作；若说明提供了包含 `SkipLicense` 等参数的安装命令，使用该条目对应的完整命令，不从其他版本照抄。
3. 打开“下载”文件夹，找到刚下载的安装文件。显示文件扩展名：`.exe` 按安装程序操作；`.msix` / `.msixbundle` 可由应用安装程序打开，但离线包需要的命令和依赖以第 2 步的说明为准，双击不一定能完成安装。
4. 核对应用名称和发布者，再继续安装。只有该版本说明明确要求管理员权限的安装步骤才使用管理员终端；完成后关闭它。若提示系统版本不支持、签名或安装包有问题，核对来源、架构和错误文字，不直接关闭系统保护。
5. 安装结束后，从“开始”菜单搜索 **Claude** 并打开。

**安装成功标志：** 能从开始菜单打开 Claude，出现欢迎、登录或应用主窗口。下载进度完成、安装文件能双击，都还不等于应用已启动成功。

成功后跳到 [账号确认](#account)。打开失败时先去 [故障处理](#troubleshooting)，不要继续 Mac 的安装步骤。

## 4. macOS 安装：DMG 与 PKG 选一个 {#mac}

| 后缀 | 安装方式 | 适合的情况 |
| --- | --- | --- |
| `.dmg` | 打开磁盘映像，把 Claude 应用拖入 Applications（应用程序） | 在个人电脑上手动安装 |
| `.pkg` | 双击后由 macOS“安装器”逐步安装 | 按组织要求安装，或进行统一部署 |

两种格式描述的是安装方式，不代表不同模型、账号套餐或免费权益。官方也将 PKG 用于企业部署；不要为了获得功能把 DMG 和 PKG 都装一遍。

### 使用 DMG

1. 在 [本站安装包下载区](/guide/manager#download-installers)选择适合 Mac 的 Claude Desktop DMG，等待下载完成后双击。
2. 在打开的磁盘窗口中，把 **Claude** 拖到 **Applications / 应用程序**。如果没有应用程序快捷图标，在 Finder 打开“应用程序”文件夹再拖入。
3. 等待复制结束，关闭磁盘窗口，并在 Finder 侧栏推出该磁盘映像。
4. 从“应用程序”文件夹打开 Claude；不要一直从 DMG 窗口内运行。首次打开时按 macOS 的来源确认提示操作。

完成 DMG 安装后直接做 [账号确认](#account)，不必再安装 PKG。

### 使用 PKG

1. 在同一下载区选择 Claude Desktop PKG，或使用组织明确要求的那一项。
2. 双击包，查看“安装器”显示的名称与目标位置，依次按“继续”“安装”等实际提示操作。
3. 若系统要求管理员验证，使用有权限的本机账号；公司设备由管理员处理。这里输入的是本机安装授权，不是星芒密钥或 Claude 登录密码。
4. 安装完成后，从“应用程序”文件夹打开 Claude。若安装器仍在报错，保留错误信息，不将其当成安装成功。

**安装成功标志：** 推出 DMG 或关闭安装器后，仍能从“应用程序”独立打开 Claude。遇到“文件损坏”“无法验证开发者”等提示，先核对下载与官方安装要求，不运行来历不明的解除限制命令。

## 5. 两个系统汇合：确认账号与功能 {#account}

### 普通 Desktop 的官方账号路径

1. 打开应用，选择登录，按浏览器或应用页面完成 **Claude 官方账号**认证；没有账号时使用官方提供的注册入口。
2. 回到应用，确认当前账号，打开新的聊天。
3. 如果 Code、Cowork 不可用或提示升级，查看官方套餐、设备要求和组织策略。官方基础聊天与付费功能的范围不同，星芒充值不会改变这些官方权益。

如果只准备了星芒账号和密钥，可以先走 [Claude Code CLI 接入](/clients/claude-code)。本站密码、安装授权码、API Key 都不能填进 Claude 官方账号登录框。

**完成标志：** 当前账号正确，能够进入普通聊天。接着做 [第一次对话](#first-chat)；登录或权益报错时去 [故障处理](#troubleshooting)。普通官方登录用户可以跳过下面的专门部署说明。

### 第三方推理和网关路径

Claude 官方提供专门的 [Desktop 第三方部署模式](https://claude.com/docs/third-party/claude-desktop/overview)。它需要对应的推理提供方、凭据、兼容网关与部署配置，认证和存储行为与普通官方登录模式有区别。

因此，**在某个位置填入本站 Key，不等于获得官方聊天、Cowork 或付费订阅权益**。CLI 的 `ANTHROPIC_BASE_URL` 和用户 `settings.json` 也不能当成 Desktop 所有功能的通用配置。只有拿到针对当前 Desktop 版本和本站渠道的具体部署说明，才继续该路径；没有这些条件时，按 CLI 教程接入星芒即可。

若组织已经配置了第三方 Desktop，请按管理员提供的登录与模型选择方式操作，不覆盖组织配置。功能范围、模型和计费由该部署及渠道决定。

## 6. 第一次对话与成功标志 {#first-chat}

1. 使用上面已完成认证的聊天入口，新建对话。
2. 输入：`请把“周日下午一起读书，带一本喜欢的书”改成一条简短邀请，不要添加具体地点或联系方式。`
3. 发送后，检查回复保留“周日下午”和“带一本书”，没有编造地点、电话或其他条件。
4. 再输入：`请保留原意，把语气改得更正式一些。` 检查它是否根据同一材料修改。

能完成这两轮，说明当前账号和该聊天入口可以处理这项小任务。普通官方账号路径在官方账号中核对用量；明确配置的本站网关路径再按 [首次调用验证](/guide/verify)核对本站记录，不能用官方聊天回复证明星芒接入。

接下来做 [Claude 第一次任务](/learn/claude/first-task)，用给定材料练习检查事实、限定输出和恢复。更多入口见 [Claude 学习路线](/learn/claude/)。

## 7. 失败时下一步 {#troubleshooting}

| 现象 | 下一步 |
| --- | --- |
| 安装包打不开或架构不匹配 | 回下载区核对系统、架构、后缀和下载是否完整 |
| Mac 推出 DMG 后找不到应用 | 确认已复制到“应用程序”，再从那里打开 |
| 一直停在登录页 | 检查是否完成官方浏览器认证、网络及组织限制；不要填本站 Key 代替登录 |
| 聊天能用，Code/Cowork 不可用 | 检查该功能的官方权益与设备要求，或组织部署规则 |
| Claude Code CLI 成功，Desktop 失败 | 分别检查两者的账号与配置来源，CLI 结果不能代替 Desktop 验收 |
| 已有第三方配置却无法连接 | 保留原配置，向部署方提供版本、模型和脱敏错误；不要自行覆盖组织设置 |

误选账号时先退出登录，再登录正确账号。想暂停只需停止任务、退出应用；不要为排错直接删除会话目录。安装问题向 [客服](/contact)提供系统版本、架构、安装包名称与错误截图，截图中遮住个人信息和密钥。
