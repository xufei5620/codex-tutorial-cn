# Hermes Agent 接入教程

Hermes Agent 是 Nous Research 推出的开源智能体工具。本篇用它的模型配置向导把本站设为自定义提供方，调用走本站%%KEY_WORD%%与额度；安装 Hermes 本身不会自动接入本站。“支持自定义模型”也不代表本站所有功能都已测试通过，终端、桌面等入口要分别确认。

从哪里开始：第一次使用，从 [安装前准备](#prepare) 开始；已经装好，直接去 [配置本站地址与%%KEY_WORD%%](#site-config)；已经配置过，去 [第一次调用](#first-call) 验证。

## 1. 安装前准备 {#prepare}

1. 按 [注册与账号准备](/guide/account) 登录本站，确认账号有可用额度。
2. 打开 [本站密钥页](%%KEYS_URL%%)，准备一个%%KEY_WORD%%。只在自己电脑的向导里粘贴，不发到聊天、截图或客服对话中。
3. 打开 [本站模型页](%%MODELS_URL%%)，复制当前分组允许的精确模型 ID。
4. 打开终端：Windows 用普通 PowerShell，macOS 用“终端”。还不熟悉终端时先看 [Node.js 与终端](/clients/nodejs) 中打开终端的部分。

**完成标志：** 已有%%KEY_WORD%%和模型 ID，知道怎么打开终端。缺账号或额度时先完成 [账号准备](/guide/account)。

## 2. 安装并确认版本 {#install}

Hermes 的安装方式随版本和系统变化，本篇不复制安装命令，请以官方项目页为准。

1. 打开 [Hermes 官方项目](https://github.com/NousResearch/hermes-agent)，找到安装说明，选择与你系统对应的方式。
2. 运行前先阅读安装脚本或安装包说明。不要从未经确认的第三方页面下载同名工具。
3. 用普通用户权限安装，不要用管理员身份或 `sudo` 来绕过报错。
4. 安装结束后，按官方帮助中的命令检查版本，确认能显示版本信息。

先不要开启消息平台网关、定时任务或陌生插件。完成模型连接后再逐项增加功能。

**完成标志：** 终端能显示 Hermes 版本信息。安装报错时记下完整错误文字，先看 [连接排错](/guide/troubleshooting)。

## 3. 配置本站地址与%%KEY_WORD%% {#site-config}

需要的三项信息：

| 内容 | 填写原则 |
| --- | --- |
| API base URL | 采用本站支持的协议地址；常见 OpenAI 兼容形式为 `%%BASE_URL%%/v1` |
| API key | [本站](%%KEYS_URL%%) 创建的%%KEY_WORD%% |
| Model | [本站模型页](%%MODELS_URL%%) 允许的精确模型 ID |

1. 改动前先找到实际使用的配置目录，复制一份备份。
2. 在终端运行模型配置向导。

```text
hermes model
```

3. 在向导中选择当前版本支持的自定义提供方选项（名称以当前版本界面为准）。
4. 按提示填入 API base URL：`%%BASE_URL%%/v1`。
5. 按提示粘贴本站%%KEY_WORD%%。
6. 按提示填入从本站复制的模型 ID，确认保存。

向导选项随版本变化，以当前提示和官方提供方文档为准。找不到适用的自定义入口时先核对版本，不要自行编造 YAML 字段。

不要把密钥复制到公共项目，也不要在没弄清作用时同时改动模型、网关、外部账户和任务调度。桌面端的配置作用域可能与启动它的终端不同，要分别查看实际提供方和认证来源，不要假定会自动共享。

**完成标志：** 向导完成且没有报错，显示的提供方和模型是刚填写的本站信息。向导报错时用备份恢复，再核对三项信息。

## 4. 第一次调用与成功标志 {#first-call}

1. 新建一个空的练习目录，在终端进入该目录。
2. 按当前版本的方式启动 Hermes 对话。
3. 在输入区发送下面的文字。

```text
这是连接测试。请用一句话回复“连接测试完成”。
不要联网，不读写文件，不执行其他工具。
```

4. 等收到完整回复后，打开 [本站控制台](%%CONSOLE_URL%%) 的调用或用量记录，核对刚才的时间、模型和状态。

文本调用通过后，再对练习目录做只读任务。外部消息发送、文件修改与插件执行都需要单独理解和授权。

**完成标志：** Hermes 收到完整回复，本站有对应调用记录。更详细的判断见 [验证第一次调用](/guide/verify)；失败时看下一节。

## 5. 失败时下一步 {#troubleshooting}

| 现象 | 下一步 |
| --- | --- |
| `hermes` 命令找不到 | 重新打开终端，再按官方项目说明检查安装是否完成 |
| 向导里没有自定义提供方选项 | 核对 Hermes 版本和官方提供方文档，不自行编造配置字段 |
| 认证失败或密钥无效 | 到 [本站密钥页](%%KEYS_URL%%) 核对%%KEY_WORD%%状态，重新运行 `hermes model` 粘贴 |
| 路径错误或协议不兼容 | 核对 base URL 是 `%%BASE_URL%%/v1`，以及渠道是否支持该协议 |
| 模型不存在或不允许 | 回 [本站模型页](%%MODELS_URL%%) 核对模型 ID 和分组 |
| 终端能用，桌面端不行 | 两者配置作用域可能不同，分别检查实际提供方和认证来源 |
| 有回复但本站没有记录 | 确认当前使用的是本站提供方，而不是其他提供方或旧配置 |

需要回退时看 [备份恢复](/guide/recovery)。仍未解决时按 [连接排错](/guide/troubleshooting) 准备版本、模型、时间和脱敏错误，再联系 [客服](/contact)；截图前遮住%%KEY_WORD%%。
