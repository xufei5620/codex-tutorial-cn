# 安全地处理一个文件夹

先完成 [第一次任务](/learn/first-task)。这次从文字对话进入文件操作，但只使用练习资料，不开放整台电脑，也不处理真实客户数据。

## 1. 手动准备练习目录

新建 `星芒-Codex-练习` 文件夹，里面只放两个手动创建的文本文件：

- `原始资料.txt`：复制上一课的蓝溪文具虚构资料。
- `要求.txt`：写下“售价 18 元、80 页、三种颜色不可变；未确认的信息留空”。

在练习目录外另存一份原始资料作为备份。不要选择桌面、下载目录、整个用户目录或真实项目作为第一次练习的工作区。

## 2. 先只读，不允许直接改

通过当前客户端的工作目录选择功能指定这个练习目录。使用命令行时，先在终端中切换到该目录，再启动已经配置好的 Codex。

```text
请先只读查看这个练习文件夹。
列出你能看到的文件，并分别概括内容。
本轮不创建、修改、移动或删除文件，不执行安装，不联网。
读不到的内容直接说明，不能假装已经读取。
```

核对它报告的文件名是否与实际一致。发现出现目录外的文件或不必要的授权请求时先停止，检查所选工作区和权限。

## 3. 先看计划，再批准一次写入

```text
请提出一份处理计划：根据原始资料生成一份 80 字以内的产品介绍。
目标文件为本目录内的 商品介绍-练习-v1.txt。
保留两个输入文件不变；若目标文件已存在，先询问，不覆盖。
先只给计划，等我确认后再写入。
```

确认计划只有一个新文件且无额外动作后，再发送：

```text
同意按照刚才的计划，仅创建 商品介绍-练习-v1.txt。
其他文件不变。完成后说明写入位置和内容。
```

出现实际权限确认时，查看动作与路径是否符合本轮计划，再决定是否批准。自然语言要求不是强制的文件系统隔离，仍需依靠客户端权限设置和人工检查。

## 4. 不只看“已完成”，要打开实际文件

在文件管理器中打开输出文件，核对售价、页数、颜色及未确认事项；确认原始文件还在且内容没变。客户端支持差异视图时一并查看，但不要只凭助手的自述判定成功。

输出文件不存在、无法打开、内容与口头报告不同，都属于未完成。请提供现象让它查明，而不是继续在错误结果上加工。

## 5. 修改与恢复

需要修改时，明确指定输出文件和改动范围，不要求它重新整理整个目录。首次练习可以让它另存 `商品介绍-练习-v2.txt`，保留 v1 方便比较。

出现误改时先停止正在运行的任务，记录受影响的文件；只有确认备份内容后才手动恢复。不要直接执行自己看不懂的全目录删除、强制重置或覆盖命令。

## 完成检查

你应当能说明：输入是什么、输出在哪里、修改了哪些文件、哪些文件没动、错误时从哪里恢复。把这五点说清楚，比让助手一句话声称“全部完成”更重要。
