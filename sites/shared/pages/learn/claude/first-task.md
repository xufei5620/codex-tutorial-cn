# Claude 第一次任务：把活动材料整理成邀请

这次练习的目标是把一份虚构活动资料整理成邀请，保留原始材料，并能说清结果哪里正确。无需写程序，也不需要接触真实客户资料。

**起点：** 已按 [Claude Code 接入](/clients/claude-code)或 [Claude Desktop 安装](/clients/claude-desktop)完成一次小对话。还没有成功回复时，先回对应接入教程。

本课按 [准备材料](#prepare) → [核对事实](#read-facts) → [生成邀请](#create-result) → [验收结果](#review-result)完成。已做完某一步可直接跳到下一步；遇到问题去 [停止与恢复](#recovery)。全程选 CLI 或普通桌面聊天中的一条路线。

## 1. 准备材料并选择入口 {#prepare}

1. 新建一个空白文件夹 `ClaudeFirstTask`。若同名文件夹已有内容，另取新名称，不把练习放进现有工作项目。
2. 在文件夹中创建纯文本文件 `activity.txt`，将下面材料完整粘贴进去并保存。Windows 用记事本；Mac 用文本编辑时先选择“格式 → 制作纯文本”。确认后缀为 `.txt`，保存为 UTF-8。
3. 复制这个文件，命名为 `activity.before.txt`，作为原始材料备份。
4. 选择下表中的一个入口，再继续下一节。不要在练习中途混换认证方式。

```text
活动：秋日读书会
日期：2026年10月18日
时间：14:00—15:30
地点：社区活动室A
人数：12人
报名截止：2026年10月15日
携带物品：每人带一本喜欢的书
费用：免费
待确认：是否提供茶水
```

| 你的入口 | 本次如何提供材料 | 在哪里检查用量 |
| --- | --- | --- |
| [Claude Code CLI](/clients/claude-code)，已接入星芒 | 让工具读取练习目录中的 `activity.txt` | 本站对应密钥的调用记录 |
| [Claude Desktop](/clients/claude-desktop)中的普通聊天，已完成官方登录 | 把材料粘贴到聊天中，最后自己保存输出 | Claude 官方账号的用量 |

Desktop 的普通聊天不必获得文件夹访问权限。本篇只有 CLI 路线让工具读写练习目录；Code/Cowork 等其他入口按各自权益和部署条件使用。

**完成标志：** 练习文件夹里有内容一致的 `activity.txt` 和 `activity.before.txt`，也已选定入口。保存失败、后缀或编码不对时先修正材料，再进入下一步。

## 2. 先核对事实，不改文件 {#read-facts}

### Claude Code CLI 路线

**运行环境：先在系统终端进入目录和启动工具，再在 Claude Code 输入框发送任务。** 使用普通桌面聊天的读者跳到本节的桌面路线。

1. 在终端进入刚创建的 `ClaudeFirstTask`。Windows 可在资源管理器打开该文件夹，再用“在终端中打开”；没有该菜单时，在 PowerShell 运行 `Set-Location "替换为练习文件夹完整路径"`。Mac 可在终端输入 `cd `，把文件夹拖入终端后按回车。
2. 运行 `pwd` 确认路径；Windows CMD 用 `cd` 查看路径。它应指向练习目录。
3. 运行 `claude --model "替换为本站可用的模型ID"`，把占位文字换成接入教程中选好的模型。工作区信任提示出现时，再核对目录。
4. 保持默认逐项确认，先用 `/status` 核对本站基址、认证来源与模型，然后发送下面的任务。

```text
只读取当前练习目录里的 activity.txt，不读取其他文件，不运行命令，不修改任何文件。
请列出8项已确认信息和1项待确认信息。
不要把“待确认：是否提供茶水”写成已经提供茶水。
完成后停下，等我决定是否生成邀请。
```

### Claude Desktop 普通聊天路线

**输入位置：Claude Desktop 的普通聊天输入框。** CLI 用户已完成上面的任务后，直接检查本节末尾的成功标志，不用再登录 Desktop。

1. 新建一个聊天，确认已登录要使用的官方账号。
2. 先粘贴本页的完整活动材料，再粘贴下面这段要求，放在同一条消息里发送。

```text
只根据上面的材料，列出8项已确认信息和1项待确认信息。
不要添加材料以外的承诺，不调用外部工具。
完成后停下，等我决定是否生成邀请。
```

**这一阶段的成功标志：** 日期、时间、地点、人数、截止日期、携带物品和费用均与原文一致，活动名称正确；茶水明确标为“待确认”。CLI 路线下 `activity.txt` 仍与 `activity.before.txt` 相同，没有生成其他文件。

若它把茶水说成已提供，先纠正：`茶水仍未确认，请只修正这一项，并重新列出已确认与待确认信息。` 核对正确后才继续。

## 3. 只生成一个邀请结果 {#create-result}

### Claude Code CLI 路线

1. 确认练习目录还没有 `invitation.md`；已有同名成果时，先备份或在提示中另取新文件名。
2. 发送下面的提示。遇到文件写入确认，核对它只新增目标文件，再决定允许这次操作。

```text
请根据刚核对的 activity.txt，在当前练习目录新建 invitation.md，写一份180字以内的中文邀请。
必须包含活动、日期、时间、地点、人数、报名截止、携带物品和费用。
茶水写为“是否提供茶水待确认”；不要添加报名链接、联系方式或其他承诺。
只允许新建 invitation.md；不要修改 activity.txt、activity.before.txt 或其他文件，不运行命令。
完成后告诉我创建了哪个文件，并停下。
```

3. 如果提示要修改别的路径、运行命令或覆盖同名文件，拒绝该操作，要求先说明原因；不要为完成练习打开全自动接受或跳过权限。

### Claude Desktop 普通聊天路线

1. 发送上面提示中关于内容的要求，把文件操作部分换成：`直接在聊天中输出邀请正文，不操作本地文件。`
2. 核对回复后，把正文复制到练习目录的 `invitation.md`，保存为纯文本。若只会用记事本，也可保存为 `invitation.txt`，验收内容相同。

**完成标志：** 练习目录里出现邀请成果文件，原始材料和备份仍在。没有文件时按 [失败处理](#recovery)确认是未写入还是聊天结果尚未手动保存，不急着重新生成。

## 4. 打开文件逐项验收 {#review-result}

1. 从资源管理器或 Finder 打开实际保存的邀请文件，不只看 Claude 的“已完成”回复。
2. 按下表逐项核对。没有通过时指出具体一项，限定只修改邀请文件或聊天中的邀请正文。
3. 对照 `activity.before.txt` 检查原始材料没有被修改。
4. 使用本站 CLI 时，按 [首次调用验证](/guide/verify)检查对应时间、密钥和模型的调用记录；普通 Desktop 官方聊天在官方账号中核对，不据此判断星芒路由。

| 检查项 | 应看到的结果 |
| --- | --- |
| 活动与时间 | 秋日读书会；2026年10月18日 14:00—15:30 |
| 地点与人数 | 社区活动室A；12人 |
| 报名与准备 | 截止2026年10月15日；每人带一本喜欢的书 |
| 费用与未定事项 | 免费；茶水仍待确认 |
| 没有编造 | 没有新增联系人、电话、报名网址或已提供茶水的承诺 |
| 文件范围 | 只有邀请成果是新文件；两份原始材料保留 |

可以这样要求一次小修正：

```text
邀请中遗漏了报名截止日期。请只补上“2026年10月15日”，其他事实与语气保持不变。
CLI 路线只修改 invitation.md；聊天路线只输出修正后的正文。
完成后列出这次唯一改动。
```

**练习完成标志：** 邀请文件能打开、表格各项通过、原文和备份保留，并且你知道这次调用使用哪个账号或渠道。返回 [Claude 学习路线](/learn/claude/)选择下一步。

## 5. 失败时停在哪里、怎么恢复 {#recovery}

| 问题 | 处理与退路 |
| --- | --- |
| CLI 找不到材料 | 停止生成，用 `pwd` 或 CMD 的 `cd` 核对练习目录和真实文件名，确认不是 `activity.txt.txt` |
| 认证、模型或额度错误 | 回 [Claude Code 接入教程](/clients/claude-code)排查；不要为恢复对话扩大文件权限 |
| Desktop 提示官方套餐或额度限制 | 检查官方账号；本站密钥不会补充官方套餐权益，可改走已配置的 CLI 路线重新开始 |
| 工具要求读取其他目录或运行命令 | 拒绝并重申只允许当前材料与目标文件；先解决范围问题再继续 |
| 内容有误或包含编造 | 指明原始材料中的准确值，只修正邀请结果，再按验收表重查 |
| 只回复完成，但没有文件 | CLI 路线检查写入是否被拒绝以及输出路径；聊天路线需要自己复制保存 |
| 原始材料被改动 | 先停止任务，对照备份，手动用 `activity.before.txt` 恢复 `activity.txt`；不要让它继续批量修复 |

想重做时先退出或停止会话，只处理本次新建的邀请文件，原始材料与备份保留。CLI 可输入 `/exit` 退出；桌面聊天可停止生成并新开对话。不要删除整个用户目录或客户端配置来重做练习。
