# 第一次任务：从提问到交付

这篇教程解决的是“接上以后怎么用”，不是重复填写地址和密钥。使用你已经完成认证的 Codex 入口；本练习只需要文本对话，不要求安装扩展、开放终端执行权限或接入其他账号。没有完成接入时，先看 [Codex 接入教程](/clients/codex)。

::: info 阅读关系
这是补充实践课，不替代原来的 11 章课程。完整课程入口将在本次整合中接入。界面名称随版本变化，请以你当前看到的控件为准；下文不要求某个固定名称的按钮。
:::

## 1. 准备一份无敏感信息的材料

复制下面的虚构资料。不要拿真实客户名单、密钥或合同练手。

```text
项目：蓝溪文具的新品介绍
产品：A5 笔记本
售价：18 元 / 本
封面：蓝、白、绿三种颜色
纸张：80 页
读者：想记录学习笔记的学生
未知信息：纸张克数、库存、快递费用、优惠活动
```

## 2. 发出一个边界清楚的请求

打开一个新的对话，先确认没有需要自动执行的后台任务，再输入：

```text
任务：根据下面的资料，写一段商品介绍。
范围：只改写表达，不添加资料之外的卖点。价格、页数、颜色必须保持一致。
材料：（粘贴上面的虚构资料）
期望：正文不超过 80 个汉字；朴素、清晰，不夸张。正文后另外列出资料里尚未确认的四项信息。
本次只输出文字，不联网、不改文件、不联系任何人。
```

点击你当前界面的发送控件。等待输出完整后再判断。出现不相关的文件写入、安装或发送授权请求时，先拒绝并确认原因，不把“同意所有操作”当成使用步骤。

## 3. 用材料检查，不用语气判断

| 核对点 | 合格标准 |
| --- | --- |
| 产品 | A5 笔记本，没有变成别的产品 |
| 数字 | 18 元、80 页，均与材料一致 |
| 颜色 | 蓝、白、绿，没有增加第四种 |
| 未知信息 | 不编造纸张克数、库存、运费、活动 |
| 交付 | 有短介绍与未确认信息，未执行额外操作 |

“写得很专业”不代表内容正确。任何资料里不存在的信息，都不能因为表达顺畅就直接采用。核对不通过时，不进入下一步发布。

## 4. 提出一次受控修改

```text
保留价格、规格和未知信息列表不变。
只把正文改得更简短，控制在 50 个汉字内。
不要添加“限时”“销量领先”“环保认证”等我没有提供的信息。
完成后列出本轮具体改了什么。
```

检查它是否只改动了指定部分。不要为了改一句话，让它重新生成无关内容。重要规则可以在修改请求中重申，不假定长对话里的所有约束一直有效。

## 5. 保存结果，明确是否完成

本练习先手动把已检查的结果保存成一个新文件，例如 `商品介绍-练习-v1.txt`，不覆盖原材料。将原始资料和最终正文分开保存。

结束前问自己：数字有没有核对？未知信息有没有标出？是不是新的文件？是否仍有需要人工确认的内容？有未确认事项时，交付状态写“待确认”，而不是假装已经正式发布。

本页为 2026-09-08 新增的学习练习，示例均为虚构，不包含实际模型调用结果。不同模型输出会不同，验收以材料和约束为准。
