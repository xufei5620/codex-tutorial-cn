# 第一次任务：从提问到交付

本课讲连接成功以后怎么用，不重复安装和填写密钥。还未连接时先看 [Codex 接入教程](/clients/codex)；完整学习路线见 [Codex 零基础](/learn/codex/)。本次只需要文本对话，不要求开放文件执行权限。

## 1. 准备虚构材料

```text
项目：蓝溪文具的新品介绍
产品：A5 笔记本
售价：18 元 / 本
封面：蓝、白、绿
纸张：80 页
读者：想记录学习笔记的学生
未知：纸张克数、库存、运费、优惠活动
```

不要拿真实客户名单、密钥、合同或个人资料练习。

## 2. 写清任务、范围、材料和期望

在新对话输入：

```text
任务：根据下面的资料写商品介绍。
范围：只改写表达，不添加资料之外的卖点，价格、页数和颜色保持一致。
材料：（粘贴上面的虚构资料）
期望：正文不超过 80 个汉字；朴素、清楚、不夸张。正文后另列尚未确认的四项信息。
本次只输出文字，不联网、不读写文件、不联系任何人。
```

点击当前界面的发送控件，等输出完整后再判断。出现与任务无关的安装、文件写入或发送授权时，先拒绝并确认原因。

## 3. 根据材料检查结果

| 检查点 | 合格标准 |
| --- | --- |
| 产品 | A5 笔记本，没有换成别的产品 |
| 数字 | 18 元、80 页，均与资料一致 |
| 颜色 | 蓝、白、绿，没有新增颜色 |
| 未知信息 | 未编造克数、库存、运费或活动 |
| 任务范围 | 输出文字，没有额外操作 |

表达专业不代表内容正确。资料没有提供的内容，不能因为写得流畅就直接采用。检查不通过时先修改，不对外发布。

## 4. 做一次受控修改

```text
保留价格、规格和未知信息列表。
只把正文改短至 50 个汉字内。
不要增加“限时”“销量领先”“环保认证”等资料中没有的内容。
完成后列出本轮改了什么。
```

核对它是否只修改指定部分。重要约束可以重申，不假定长对话里的每条要求始终有效。

## 5. 保存并确认完成状态

手动把检查后的结果保存为新文件，如 `商品介绍-练习-v1.txt`，不覆盖原材料。原始资料与最终正文分别保存。

结束前确认数字、未知信息与文件位置。有待人工确认的内容，就标注“待确认”，不把草稿当成已正式发布的结果。

下一步：[安全地处理一个文件夹](/learn/working-with-files)；已有结果需要继续调整时读 [检查结果与修改](/learn/review-and-revise)。

本页所有示例均为虚构，不包含真实模型运行记录。验收以材料和约束为准，不要求模型输出与某段示范文字完全相同。
