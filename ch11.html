11.1术语表

英文条目在前（按字母），中文条目在后（按拼音）。每条只解释到「够用」为止，解释里出现的其他术语也都能在表里查到。

术语解释出现在
AI（人工智能）能读懂文字、生成文字的一类软件技术。Codex 建立在这类技术之上。第 2 章
API / API 密钥开发者之间约定的技术接口，以及使用它的钥匙。普通用户用不到；登录页的「用其他方式登录」就是给它准备的。第 1、3 章
ChatGPT Classic旧版桌面应用，不含 Codex。不要下载它。第 3 章
ChatGPT 桌面应用OpenAI 的桌面软件，2026 年 7 月起包含 Chat、Work、Codex 三个视图。本教程里的 Codex 就是其中的一个视图。第 3 章
CLI（命令行）靠打字输入命令来操作电脑的方式。网上资料里提到的「Codex CLI」是给程序员用的命令行工具，本教程未核实其细节，也不涉及。第 1、3 章
Codex本教程的主角：ChatGPT 桌面应用里的一个视图，能读你的材料、写东西，还能在你允许的范围内替你动手（改文件、上网、操作其他工具）。全书
Git程序员记录文件改动历史的工具。本教程不涉及；界面里的 Worktree、Pull request 等选项与它有关，可以忽略。第 1、3 章
Skill（技能）一份固定的「怎么做事」说明书，存在电脑里的一个文件夹中，用 $ 调用。第 7 章
SKILL.md每个 Skill 文件夹里必有的说明书文件，普通文本。第 7 章
插件（Plugin）可安装的能力包，让 Codex 能碰到你在其他软件里的东西；常需要授权你的账号。第 6 章
定时任务（Scheduled tasks）让 Codex 在固定时间自动做某件事，比如每周一整理周报。侧栏的 Scheduled 里管理。第 8 章
记忆（Memories）让 Codex 记住你的偏好，跨对话生效。默认关闭，在 Settings → Personalization 里开关。第 5 章
蓝溪文具本教程所有练习用的虚构文具店。老周（店主）、小梅（店员）、李姐也都是虚构人物。全书
连接的应用 / connector / MCP插件里负责「连到外部服务」的那部分，三个词在官方文档里常混用。对普通用户来说就是「交给它一把钥匙」。第 6 章
模型Codex 背后具体干活的 AI「大脑」，输入框下方可以选。新手用默认即可。第 3 章
权限模式输入框下方的选择器，决定 Codex 动手前要不要问你。本教程全程用 Ask for approval。第 3 章
三分法检查输出时把内容分成「材料里有的」「合理推断的」「凭空出现的」三类分别处理。第 5 章
沙盒 / 工作区边界Codex 默认只能读写你指定的那个文件夹，这个「圈」就是沙盒。要出圈时会先问你。第 3、5 章
审批卡 / 审批弹窗Codex 要做有影响的动作前弹出的确认框。看不懂就拒绝。第 3、6 章
审阅面板（review panel）Codex 改了文件后，逐行显示改动的地方，并提供撤销（边界见 5.4）。第 3、5 章
四要素任务、范围、材料、期望——写清楚一个请求的四件事。第 4 章
脱敏把材料里的真实姓名、号码换成代号或打码，处理完再换回来。第 10 章
项目（Project）侧栏 Projects 里的一项，通常对应你本机的一个文件夹（Local project）。第 3、8 章
用量额度每 5 小时和每周可以让 Codex 干多少活的上限，不同套餐不同。到限不是故障。第 3、10 章

11.5发现错误怎么反馈

软件界面更新很快，教程一定会有过时的地方。如果你发现某一步和屏幕上看到的不一样，请到教程的 GitHub 仓库提交一条 Issue（github.com/xufei5620/codex-tutorial-cn/issues），用第 10 章 10.5 的五要素写清楚：你的系统、教程的哪一章哪一步、你看到了什么、教程说应该看到什么，最好附一张打过码的截图。没有 GitHub 账号也没关系，注册一个只需要邮箱。
