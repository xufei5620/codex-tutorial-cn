提示词效果图约定

效果图只负责把提示词意图、约束和结果摆清楚，不负责替代课程正文，也不负责伪装成真实界面。任何图片都必须能回链到 Prompt ID 和媒体 ID。

硬规则：不要为了凑版面创建空图、假图或没有登记的占位文件。没有真实来源、真实生成记录或真实复核结论的图片，不进入公开课程，也不进入 Notion 投影。

行业映射

行业名称用于图片目录、登记表、Notion 投影和维护说明的同一套口径，并写入小写的 industry 字段。当前示例绑定的是课程已有的通用 Prompt 卡；未来行业专用 Prompt 卡仍须先进入 src/modules-v1.json，图片文件名保留可读的行业英文名。

行业用途范围媒体 ID 示例
ecommerce商品图、活动页、促销横幅、转化型展示图IMG-PROMPT-ECOMMERCE-0001
education课程封面、教学示意、学习路径、知识卡片IMG-PROMPT-EDUCATION-0001
marketing品牌活动、社媒宣传、广告概念、活动海报IMG-PROMPT-MARKETING-0001
design界面概念、品牌视觉、构图示意、风格探索IMG-PROMPT-DESIGN-0001
office办公流程、管理看板、协作示意、流程图式效果IMG-PROMPT-OFFICE-0001

命名规则

IMG-PROMPT-<UPPERCASE-INDUSTRY>-<four-digit-sequence>

  • 媒体 ID 中的行业段必须大写；登记表的 industry 字段仍取小写的 ecommerce、education、marketing、design、office 之一。
  • <four-digit-sequence> 是四位零填充序号，按行业各自递增，不跨行业共用流水号。
  • 同一张图只允许一个 ID；同一 ID 不能对应多个文件，也不能复用给不同版本的图。

Prompt ID 绑定

Prompt ID 是提示词卡的稳定主键，格式为 PRM-XXX-NNNN。下列是当前可解析到课程 src/modules-v1.json 的通用提示词卡；它们仅为计划中的行业效果图绑定示例，不代表已有媒体文件。

媒体 IDPrompt ID绑定方式
IMG-PROMPT-ECOMMERCE-0001PRM-COM-0001计划中的行业条目；同一行业、同一提示词卡、同一版本的一对一绑定。
IMG-PROMPT-EDUCATION-0001PRM-COM-0002计划中的行业条目；媒体和提示词都来自同一份维护记录。
IMG-PROMPT-MARKETING-0001PRM-COM-0003计划中的行业条目；如果图像换版，必须新开媒体 ID。
IMG-PROMPT-DESIGN-0001PRM-COM-0004计划中的行业条目；页面展示、Notion 投影和 Git 记录都引用同一对 ID。
IMG-PROMPT-OFFICE-0001PRM-COM-0005计划中的行业条目；办公类示意图也按同样规则登记。

同一批当前可解析的示例还包括 PRM-COM-0006；只有在实际媒体生成、来源和权利均已复核后，才可为它新增对应的媒体登记记录。

复核与停用

  • 只要图片改成生成示例，就必须把 generated-example 写进来源类型和说明，不得包装成真实照片、真实截图或官方素材。
  • 权利状态是 pending、来源缺失、许可冲突、GitHub 路径缺失、或最后复核日期过期时，公开投影停止使用该图。
  • Notion 只能做展示和复核，不是图片的权威库；权威记录永远在 Git 的媒体目录和登记表里。
